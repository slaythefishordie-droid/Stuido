# Knowledge Studio v1.0.0

原生 iPad 知识整理与 Safari 学习工具，最低 iPadOS 17。

## 主要功能

- 四类卡片、My Inbox、AI Inbox、JSON 文件/粘贴校验、资料匹配和确认导入。
- 项目与资料库、PDF/EPUB 选文和定位、本地视频时间 Mark、词典外链。
- Data Manager：批量归档、回收站、引用保护、版本化 ZIP 备份和校验恢复。
- Safari：QuickMark、0–3 秒回溯、±1/2/3 秒精听、A–B 循环、历史搜索/备注/复制链接/删除和书签备份。
- 个性化设置，以及逐站授权的文章选文和页面音频采集。

## 安装与数据

下载 IPA 后使用 AltStore Classic 在用户设备上重签，安装时保留 Safari 扩展。IPA 的 ad-hoc 签名仅保留权限声明，不是 Apple 设备分发签名。保留相同应用身份以延续已有数据。

旧 prototype-v1 原件保留，迁移保留稳定 ID 和秒数。备份含知识库和已有本地资料；在线资料仅保存链接。恢复前请保留独立备份。

## 验证范围与限制

发布时补入本次实际构建运行、测试结果和 IPA SHA-256。里程碑 1 的双向共享由用户真机确认；本版新增阅读器、Safari 页面变体和真实旧书签备份仍需用户资料复验。

旧备份兼容已使用合成 youtube-time-marks v1 样例验证，当前工作区没有原脚本/真实旧备份，不能宣称完全互通。扫描 PDF 不提供 OCR，不接 DRM；站点没有可读取 audio 元素时无法捕捉音频时间。系统全屏/PiP 不保证网页控件可见。

复习调度、知识图谱等后续产品阶段不在此次阶段 1–4 范围。SQLite 首版使用经过引用校验的事务聚合快照，后续大数据量分表优化独立迁移。
