# Safari 网页采集路线图

当前开发顺序如下。每个里程碑都以用户可观察的行为验收，结果记入[验收记录](progress.md)。首个适配器面向 iPad Safari 中的 YouTube 普通视频原页面。

| 里程碑 | 交付 | 验收条件 |
| --- | --- | --- |
| 1 · 验证分发与共享 | 随 SwiftUI 主 App 打包一个 Safari Web Extension，在 GitHub Actions 构建设备 IPA，再用 AltStore Classic 免费账户重签安装。 | 分别记录含扩展的设备构建、免费重签后主 App 和扩展的安装、Safari 识别并启用扩展，以及两端实际读写同一 App Group 的结果。用扩展写入一条可辨认的数据，主 App 冷启动读取，再由主 App 写入并让扩展读取。 |
| 2 · 打通一条 Mark | 在 Safari 的 YouTube 原页面点击 QuickMark，经本地 Native Messaging 和 App Groups 持久保存，切回主 App 后自动进入 My Inbox。 | 播放继续，无表单、无 App 切换。核对出处链接、时间戳和唯一 ID。主 App 当时未运行、保存后重启、交接中断后重试或同一标记重复送达，最终都能找到同一条记录。用户明确操作后才建卡或加入复习。 |
| 3 · 迁移完整 QuickMark | 对照用户提供的 2.0.0 脚本迁移精听、历史、回看与备份功能，补齐双向 2 秒微调。 | 在 iPad 横竖屏和分屏下逐项完成下表；用实际学习视频及旧书签备份复验。正式扩展随主 App 安装，不依赖第三方 Userscripts。 |
| 4 · 完善网站适配器 | 从 YouTube 的实际用法提炼一个扩展内的通用适配器接口，为在线文章、播客预留接入方式。 | 用文章的出处与段落定位、播客的出处与时间定位检验接口能否表达两者。网站页面变化在对应适配器内处理，共用 Source、Mark、My Inbox 与去重流程。此步验收的是接入能力。 |

免费重签能否保留嵌入的扩展及双方匹配的 App Groups 权限，必须用用户的 iPad 实测。若受限，记录安装选项、实际权限及失败环节，后续里程碑的端到端验收保持待验证。

## 交互方向更新 · 2026-11-19

按产品设计章程，只有 Mark 核心按钮常驻，另有独立控制入口；展开后 ±1/3 秒与 A–B 等高频操作清晰可见。既有 ±2 秒保留，不因布局优先级调整删功能。此为新设计目标，真机布局验收尚未完成。

## YouTube 适配器迁移对照

来源为用户提供的 `youtube-timestamps v2.user.js`，脚本名称「YouTube 随手时间书签」，版本 2.0.0。文件 SHA-256 为 `76e91ceeb5e98866dbdfde48e71c73867e44c8aee2cdba7f0b8efc8376515adc`。以下根据源码核对；Safari 扩展的真机结果另行记录。

| 能力 | 用户行为与边界 |
| --- | --- |
| 一键标记与提前量 | 保留视频标题、出处、标记时间和创建时间。提前量可选 0、1、2、3 秒，脚本默认 2 秒并记住偏好。保存位置取当前秒数减提前量，脚本向下取整，最低为 0。例如 12.8 秒按标记、提前 2 秒，书签定位为 10 秒。回看使用已保存的位置。保存成功后轻提示，读取失败或写入未确认时给出失败状态。 |
| 精听微调 | 前进、后退分别提供 1、2、3 秒，止于视频起点和终点。原脚本实际只有 ±1、±3 秒；±2 秒是此次明确新增的档位。 |
| A–B 循环 | 设 A，再设晚于 A 的 B，回到 A 循环，可清除和重设。切换视频、跳到书签或手动微调越出循环区间时清除循环。暂停时保持暂停。 |
| 历史与回看 | 全部记录按创建时间倒序，可按标题、备注、显示时间搜索；仅看当前视频时按时间正序。保留计数、分批显示、加改备注、复制含时间的链接、确认后删除。当前视频内跳转，跨视频在 Safari 原站按出处和时间回看。 |
| 旧数据与备份 | 支持原脚本书签 JSON 导出、导入及合并。识别旧格式 `youtube-time-marks` v1，验证记录，确认后导入；相同视频与时间的旧书签跳过，保留已有备注，中断后可重试。原脚本限制 10 MiB、20,000 条。旧文件兼容与 ChatGPT 卡片包分别验证。 |
| 触控与反馈 | 保留一键标记、可收起的精听和书签面板、清晰的选中状态、可读的保存反馈、安全区及适合手指的按钮。验证窄分屏、焦点和网页快捷键互不干扰。 |
| 适用页面 | 覆盖桌面版和移动版普通 watch 页面，同标签页换视频后检查出处。广告、未就绪和无效时间不给出成功标记。原脚本未支持直播和 Shorts；原生全屏、画中画中无法显示网页控件，按实测记录适用范围。 |

脚本中的 GM 存储 API、旧备份键及按“视频＋秒”判重只描述旧数据的兼容行为。扩展交接按标记唯一 ID 去重。Native Messaging 的消息流、重试方式、共享存储格式、适配器接口与代码结构留待实施决定。[数据模型与架构](data-model.md)
