# Knowledge Studio 使用指南（V2 开发候选）

本页描述当前代码入口；实际编译、测试和设备验收见[开发进度](progress.md)。本轮完成后也不构建 IPA，等待用户另行安排。文件名沿用历史链接。

## 阅读与出处

- **书桌**显示继续阅读、研究项目、最近更新的知识，安静保留今日复习入口。侧栏选择资料库、收集箱、知识卡片和整理工具；设置可选紧凑/舒展、明暗外观。
- **PDF**保留原排版。选文菜单保存单词/语料/关键词/关键句高亮，或打开批注、系统词典、发音；底部还可保存页码。扫描页开启“区域标记”，长按拖出范围；跨页区域分次保存。“识别本页文字”使用设备 OCR，核对结果后保存区域摘录。
- 文件指纹相符、文字范围及上下文一致才显示精确文字定位；有可靠坐标显示精确区域；旧无指纹记录只承诺页面；文件不符或页码无效不猜测跳转。异常文本层用视觉区域，不把 OCR 当精确文字。
- **EPUB**选中文字后选择四色高亮，点击已有高亮编辑备注。阅读设置提供衬线/无衬线、字号、行距、页边距、暖纸/纸白/夜读、自动/单页/双页。固定版式书籍可能限制重排。旧记录若只有章节进度，会明确提示精度不足。
- 四色统一：单词蓝、语料黄、关键词紫、关键句绿。标记进入收集箱，不强迫立刻分类或建卡。卡片出处可直接回跳；宽屏可与原文并排对照。
- 本地视频保存实际播放秒数。网页文章/播客/视频出处在 Safari 打开。缺失文件可绑定相同原件，保留已有标记和卡片。

## 发音与词典

Apple 系统词典保持可用。阅读器选词和单词卡的“听发音”共用一套播放服务：先找缓存真人录音，再查询开放资源，无匹配则用 Apple 设备语音。设置英美偏好，界面标明实际口音、真人/合成、录音者和许可链接。

只有主动发音时将所选短词发往维基词典/Commons。没有账户、商业录音或上传整篇阅读内容。许可/来源不明确或格式不可播放时回退。缓存最多 100 条、约 50 MB，由系统管理，不在知识库备份中；设备需有可用的英语语音才能离线 TTS。开放资源不覆盖所有单词、口音或同形异音词义项。

## 知识组织

- **资料库**宽屏左侧项目、右侧内容，窄屏逐层直接打开。工具栏导入 PDF/EPUB/本地视频；“选择”后批量移入回收站。项目中默认打开内容，“管理关联”才编辑成员。
- **项目分组**按研究主题组合资料和卡片。分组移除不删除内容。项目资料旁的“项目研究笔记”只属于当前项目，同一资料的文件、高亮和 Mark 在多个项目共享。
- **研究白板**添加概念、笔记、资料、卡片。点击节点打开，拖动布局，长按编辑文字、连线、移除。连线模式再点目标即可连接；“连线”面板管理边。“撤销”保留本次页面最多 20 次布局操作，发生外部修改时拒绝覆盖。
- **知识卡片**四类清晰筛选，也可切换词汇库（单词/关键词）与语料库（语料/关键句）；搜索覆盖内容、笔记和标签。建卡、收藏、归档和加入复习相互独立。
- **收集箱**按资料分组。查看摘录、编辑备注、回到出处、整理成卡；显式选择后批量归档或移入回收站。

## 今日复习

在卡片编辑中主动加入复习，今日页面分为现在到期与今天稍后。打开原卡后自评忘记/困难/良好/轻松；不新增题型。FSRS-6 原子保存状态、调度参数、版本和每次前后记录；重复提交不会重复计数。

今日的目标保持率用于新加入调度的卡。已有卡可在“复习记录与调度”修改保持率，保留当前到期时间，从下一次评分起生效。暂停/退出不删除卡片或历史。旧历史缺少调度状态时会阻止猜测重建；未来升级另行兼容处理。

## Safari 学习

在 Safari 启用扩展并授权网站。QuickMark 常驻，独立控制入口展开 ±1/2/3 秒、A–B、历史和回溯。保存不暂停视频；失败重试保留同一 ID。设置支持字号、控件位置及逐站文章/音频授权。原生音频元素不可读、DRM、直播和特殊播放器不承诺支持。

旧书签保留原件，导入先预检确认；当前支持 `youtube-time-marks` v1 的 marks/bookmarks 列表，真实旧脚本备份仍待样例复验。

## 导入、管理与备份

导入箱支持 JSON 文件/粘贴 → 校验 → 匹配资料 → 预览去重 → 勾选 → 确认事务入库。导入说明与个人笔记独立，协议键名保留英文以兼容现有文件。

数据管理支持搜索、筛选、多选归档、直接回收站与恢复。永久清理保留确认及引用保护；项目分组、笔记、白板引用也参与保护。删除项目或布局不删除原资料/卡片。

完整 ZIP 备份包含知识库、回收站、标记、项目语境、白板、复习状态与历史、本地原始资料；在线资料保存链接。恢复先校验版本、路径、CRC、摘要与引用，再明确确认替换；替换前保留本地快照。恢复失败不通过清库修复。缓存音频、设备偏好不属于知识库备份。

## 延后的设备验收

未来按用户安排用真实资料验证：阅读 → 标记 → 收集箱 → 卡片 → 精确回跳；字号/旋转/分屏后定位；扫描 PDF；断网发音；复习重开；删除恢复；包含新数据的备份恢复；大文件与异常退出。当前不安装、不构建 IPA，不用旧包冒充新版验收。
