# 阅读与整理操作补充（1.0.1 候选）

以下新交互随本轮候选验证，真机验收结果见开发进度。

- 书房侧栏分为阅读与思考、整理与维护。设置可切换紧凑显示和外观；窄屏通过侧栏按钮返回模块导航。
- EPUB 选中文字，在选文菜单选择单词/语料/关键词/关键句高亮。蓝/黄/紫/绿代表四类卡片；点击高亮可编辑备注与颜色。仅保存当前页位置使用底部“保存当前位置”，不会伪装成选文高亮。
- 阅读设置包含字体、字号、行距、书页主题与宽屏自动双页；书籍固定版式可能限制设置。旧记录缺少完整选文定位时会提示仅回到章节/进度。
- 收集箱按资料分组，默认按标记颜色整理为对应类型卡片，也可选其他类型；编辑/选择模式批量归档或移入回收站。
- 项目中点击资料/卡片直接打开，“管理关联”才显示关联控制。解除关联不会删除内容。
- 宽屏卡片详情的出处中可选择“与原文并排对照”；窄屏仍可直接打开出处，不压缩阅读到不可用宽度。
- 数据管理点击内容打开；批量处理先进入编辑/选择模式，知识库与回收站直接切换。备份/恢复展开后操作，永久清理保留确认与引用保护。
- Safari 标记按钮保持独立；阅读控制展开后提供精听、A–B、历史与回溯。重试保留原 ID，精听 ±2 秒仍保留。

# 0.3 开发版使用与验收

本页描述开发代码的入口。是否已通过本轮编译、测试和真机验收，以 PROJECT_STATUS.md、progress.md 的最新记录为准。不要用旧版 IPA 验收新功能。

## Safari 学习

1. 在 Safari 启用扩展并允许 YouTube；普通 watch 视频页面出现 QuickMark。
2. 设置默认回溯 0–3 秒。点击保存不暂停；成功后回到 App 的 My Inbox。失败时用“重试上一条”保留同一 ID。
3. 展开精听与历史，使用 ±1/2/3 秒、A–B、搜索、仅当前视频、备注、复制链接与删除。删除对应 App 回收站。
4. Safari 扩展菜单现在包含回溯、字号、左右位置、默认收起，以及网站适配器设置。为当前 HTTPS 网站主动授权后，可保存文章选文或页面 audio 的真实时间。没有可读取音频元素、直播、未就绪、DRM 和特殊站点播放器不宣称可采集。
5. 旧备份先保留原件，导入会预检并确认，相同视频＋秒数跳过，不覆盖已有备注。真实旧脚本备份仍待用户样例复验；当前兼容 `youtube-time-marks` v1 的 marks/bookmarks 列表，记录字段为 videoId/videoID、time/seconds、title、createdAt、note。

## 整理与导入

- My Inbox：查看摘录／定位，回到出处，选择四类卡片之一整理。建卡、归档 Mark 和选择复习状态是独立操作。
- 卡片：查看全部、Dictionary 或 Corpus；编辑类型内容、语言、标签、个人笔记、整理状态、复习选择与项目关联。四类卡片之外不新增类型。每日复习调度属于产品阶段 6。
- AI Inbox：粘贴或选取 JSON 文件 → 校验候选 → 选择批次 → 匹配资料 → 生成预览 → 筛选卡片及项目 → 确认导入。已有相同内容默认不勾选；导入说明与个人笔记分开。使用仓库 examples/import/valid-four-types.json 可验收四类联合导入。重复确认同一批次应拒绝。
- 右下角加号是各主页面的快速建卡入口。

## Library

- 创建项目、关联/解除关联资料与卡片；解除关联和删除项目不会删除内容。
- 导入 PDF、EPUB、MP4/MOV/M4V。已知相同摘要复用资料；离线管理。PDF 可保存页码、选文与高亮；扫描页无文字层时只保存页码。EPUB 使用 Readium，保存选文 locator 和高亮；不接入 DRM。
- 本地视频通过系统播放器读取实际秒数。Mark 出现在 My Inbox，可整理为卡片并返回原定位。
- 导入 JSON 中缺少本地文件的资料可以在出处页绑定原始文件；已有摘要时必须一致。缺失资料不删除卡片。
- 在线出处在 Safari 打开，不在 App 建完整浏览器。卡片详情提供词典外链。

## Data Manager

- 按对象类型与文字筛选，多选归档或移入回收站；删除前展示关联影响。
- 恢复保留 ID；有关联端点在回收站时，先恢复出处/端点。永久清理需单独确认；仍有引用的对象拒绝清理。
- 完整 ZIP 备份包含当前知识库和已有本地资料，在线资料仅保存链接。分享导出到“文件”后，选择备份进行校验，再确认替换。
- 恢复校验版本、路径、ZIP CRC、文件摘要、对象引用与实际解压大小；替换前保留本地恢复快照，数据库提交失败则回滚。
- 清理未引用文件会保留当前库、回收站及恢复前快照引用的文件；快照默认保留，会占用空间。

## 本轮真机验收重点

用测试资料先完成：Safari Mark → Inbox → 卡片 → 出处；JSON 候选 → 资料匹配 → 确认导入；PDF/EPUB/视频 Mark → 杀进程重开 → 回跳；删除 → 恢复；备份 → 修改测试卡片 → 恢复并核对卡片/资料/关联。再验证横竖屏、分屏、断网与扩展后台重试。

首次使用新恢复流程时，请保留独立的原始资料和备份文件。测试失败记录操作、错误原文、IPA 对应 commit 与资料类型，不通过清空数据修复。
