# 页边书房原型定稿

[下载离线原型](preview.zip)，解压后打开 `prototype.html`。书桌有一张主思想卡、三张按内容排版的小卡、三个活跃项目和紧凑的续读入口。资料库展示 PDF、EPUB、视频和网页封面并可更换。Reader 打开 PDF 时展示工具栏、原生文字高亮的视觉样式和独立笔迹的样式。

[Home](home.png) · [卡片展开](card.png) · [资料封面](library.png) · [PDF 勾画](reader.png) · [EPUB 页边](reader-epub.png) · [原生 SwiftUI 与 Apple Pencil 2 规划](pencil-plan.md)

## 如何体验

1. 点击首页绿色关键句卡，编辑思考笔记，再点底部章段出处。页边线、语义色和焦点把卡片带回原文。
2. 在资料库点开《城市的背面》。用鼠标在 PDF 样页上画线或圈选，可切换荧光笔、整笔擦除、撤销与重做。切到「选择／导航」，选中文字再点 Mark 可尝试文本高亮。也可切换 EPUB 查看章段笔记与下划线。该浏览器样稿的笔迹和笔记仅用于会话演示。
3. 「更换封面」可从本地读入自定义图，并恢复到原资料图片或模板。原型用浏览器本地存储缓存自选图，存储不可用时只保留当前会话。示例书影沿用首轮摄影，其他缺封面资料由稳定 ID 选择编辑式图案，再由资料类型决定形状。预览包不需要联网或生成式服务。

## 视觉与组件

- **思想卡展开为笔记页。** 保留卡面的题句和色线，以卡片原位置为起点展开。原文仍可从笔记页尾抵达，阅读器将焦点放在原段落。关键词用页边短线带出概念，单词用英文例句，语料突出可复用短语，主关键句保留宽松行距。
- **书签式转场。** 打开资料时，封面收束到 Reader 的书名旁，阅读时保留来源身份。支持系统减少动态效果设置，浏览器缺少转场 API 时仍可直接打开和回跳。
- **沿用纸面与深梅。** 纸面 `#F6F1E8`、书页 `#FFFBF4`、衬纸 `#EEE5D7`、墨色 `#2E262A`、深梅 `#3C2637`、操作赭铜 `#7D463B`。标题和引文用宋体，操作用无衬线。四类卡采用蓝 `#356780`、黄 `#775516`、紫 `#6D4D86`、绿 `#3D6750`，配文字标签和浅底色。Reader 工具可整组贴左或右，窄空间换行。Home 按模块分区，为将来的布局偏好保留模块身份。
- 继续使用[第一轮 Moodboard](moodboard.png)和[第一轮历史审计](https://github.com/slaythefishordie-droid/Stuido/blob/ac13bbed50b2201f4ee1f9c8ba45d90464a461de/design-lab/README.md)。
