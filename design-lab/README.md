## 设计选择

- **文学月刊**强调刊首和内容编排，适合让书桌每次聚焦一本书。弱点是项目浏览和回到出处缺少共同的视觉线索。
- **馆藏索引**强调封面、分组与展签，适合快速比较资料。长时间阅读需要另外建立舒适的版心。
- **页边书房**把书脊、摘录的细线和原文页边联系起来。选择它是因为这个线索既能承载书房的视觉识别，也能解释一条摘录来自哪里。编辑式首页与馆藏封面的优点保留在各自的场景。

两处原创细节是「同色页边线」和「同一书系的占位封面」。前者用配对的颜色、中文类型与章段位置连接书桌、批注和原文，按回跳后焦点跟随到段落。后者让无封面的 EPUB 有纵向书脊，PDF 有纸张叠边，视频有宽画幅和播放标识，靠形状便能扫出类别。正式实现优先采用资料内已提供的封面。

布面书摄影为本实验生成，原型中的文字、作者和封面均为示例。参考只用于研究构图、材质和交互方法。[Kinfolk 排版](https://alexhunting.studio/blogs/projects/kinfolk) · [Penguin 装帧](https://www.penguin.co.uk/discover/articles/clothbound-classics-little-history-making-of) · [Walker 的线条与识别系统](https://www.walkerart.org/reader/andrea-buttner-the-making-of-a-visual-identity/) · [Apple Books 阅读工具](https://support.apple.com/zh-mo/guide/ipad/ipadc8494b6b/ipados)

## Design Tokens 与组件

| 用途 | 原型定义 |
| --- | --- |
| 表面 | 纸面 `#F6F1E8`，书页 `#FFFBF4`，衬纸 `#EEE5D7`，分隔 `#D9CABC`。主图表现窗光与布纹，正文表面用稳定的纯色。 |
| 文字与操作 | 墨色 `#2E262A`，辅助文字 `#6A5A57`，深梅 `#3C2637`，操作赭铜 `#7D463B`。标题和引文用 Songti SC / Noto Serif CJK SC，控件用 PingFang SC / Noto Sans CJK SC，拉丁衬线用 Georgia。 |
| 四类卡色 | 单词蓝 `#356780 / #DCEBF3`，语料黄 `#775516 / #F3E4B7`，关键词紫 `#6D4D86 / #E9DEF2`，关键句绿 `#3D6750 / #DCE9D8`。前者作字及细线，后者作底或选文。类型始终有文字标签。 |
| 层级与间距 | 页面边距 24–64，紧窗口 17，模块间距约 16–27。页面标题 44–73，章节正文 17–19、行高 1.9。常用控件最小高 44。 |
| 基础组件 | 阅读入口：标题、作者、进度、单一主动作。资料封面：真封面优先，缺图按类型占位。出处卡：引文、中文卡类、出处定位与回跳。工具使用细线分隔、可见焦点与短暂选文反馈，尊重减少动态效果选项。 |

## SwiftUI 接续

1. 设计确认后，先在现有 `StudyAppearance` 上加语义色、字级和密度，以及可复用的阅读入口、媒体封面和出处卡。用动态颜色和 Dynamic Type 承接现有深浅色与紧凑/舒展选项。
2. 第一批只改 `StudyHomeView` 的书桌排版，继续用现有最近阅读排序、导航和 Today 调度。第二批在 `LibraryView` 加封面浏览，保留项目树、原列表、导入和显式批量选择。第三批把出处卡接到 `CardDetailView` 和 `SourceReaderView`，保留 locator 精度及失败提示。PDF 维持原版式，EPUB 继续用 Readium 重排。
3. 分别用 iPad 横屏、竖屏、分屏窄窗核对导航、原文回跳、键盘、VoiceOver 与大字体。收集区、导入与 Data Manager 在阅读闭环验收后逐页处理。管理页保留专业表格和批处理语义，收集端突出出处和待处理内容。

## 原型验证

Chromium 渲染 Home、Library、Reader 与 Moodboard。首轮评审将方形媒体封面改成 EPUB 书脊、PDF 纸张和视频宽画幅，并弱化 Reader 的侧栏。复核三页的桌面输出与窄窗，验证 1440、834、640、390 px 宽度无横向溢出。确认出处焦点、批注收放、搜索、格式与项目过滤、封面信息弹窗和 Escape 关闭。范围是浏览器静态原型，使用示例数据。真实 SwiftUI 的暗色、VoiceOver 与旋转仍需单独验证。
